🎨 OpenCode Figma Setup

Auto-setup tool for design tokens, typography, and components

🎨 Color Tokens

All 12 colors from your design system. Click any color to copy its hex value.

How to Add These Colors to Figma

  1. Open your Figma file: OpenCode Design System
  2. Go to Assets panel: Right sidebar → Colors section
  3. Create color token: Right-click → "Create color"
  4. Name and hex: Enter name (e.g., "Charcoal") and hex value (e.g., #1A1A1A)
  5. Repeat for all 12 colors (takes ~10-15 minutes)

📝 Typography Tokens

Font families, sizes, and weights for your design system.

How to Add Typography to Figma

  1. Go to Assets panel: Right sidebar → Typography section
  2. Import fonts: Search for "EB Garamond" and "Inter" from Google Fonts
  3. Create typography styles: For each style below (H1, H2, H3, Body, etc.)
  4. Set properties: Font family, size, weight, line height
  5. Save as style in Figma typography library

🧩 Components

6 main components ready to build in Figma. Frame sizes and structure provided.

Component Setup Instructions

  1. Create new page: In Figma, add a new page named "Components"
  2. For each component below:
    • Create a Frame with the specified size
    • Name it exactly as shown (e.g., "Navigation")
    • Set background to Off-White (#F5F0E8)
    • Add placeholder text with EB Garamond (heading) and Inter (body)
    • Apply color tokens from your color library
  3. Create variants: For each component, create variants for responsive (Mobile/Desktop) and interactive states (Hover/Default)

💡 Next Steps

  1. Add design tokens to Figma (colors, typography)
  2. Create component frames in Figma (use provided sizes and specs)
  3. Install Figma-to-Code plugin: Use Builder.io or similar
  4. Export components: Generate React + Tailwind code
  5. Integrate into your project: Copy generated code to [src/components/](../src/components/)

⚠️ Important Notes

Animations: Figma auto-generation handles static layouts well but struggles with Framer Motion animations. Document animation specs separately or implement manually in React.

Design tokens: Make sure all text/colors use Figma design tokens (not hardcoded hex values) so generated code will use Tailwind classes instead of inline styles.

📖 Complete Setup Guide

Step-by-step instructions for setting up your Figma design system.

Phase 1: Design Tokens (15-20 minutes)

  1. Open your Figma file: OpenCode Design System
  2. Go to Assets panel (right sidebar)
  3. Click on Colors section
  4. Create all 12 color tokens (see Colors tab for list)
  5. Click on Typography section
  6. Create all typography styles (H1, H2, H3, Body, Body Small, Caption)
  7. ✓ Phase 1 complete

Phase 2: Component Library (30-45 minutes)

  1. Create a new page named "Components"
  2. Create component frames for each of the 6 components (see Components tab)
  3. Apply design tokens to all elements (no hardcoded colors)
  4. Create variants for responsive (Mobile/Desktop) and states (Hover/Default)
  5. ✓ Phase 2 complete

Phase 3: Auto-Code Generation (10-15 minutes)

  1. Install plugin: Go to Figma Plugins → Search "Builder.io" or "Token Studio"
  2. Configure: Set export format to React + Tailwind CSS
  3. Test export: Select one component and export to code
  4. Verify: Check that generated code uses Tailwind classes (text-charcoal, bg-offwhite, etc.)
  5. Paste code: Copy to your React component files
  6. ✓ Phase 3 complete

Phase 4: Workflow Documentation (5 minutes)

  1. Document your design-to-code workflow
  2. Share Figma file with team
  3. Establish code review process that includes Figma verification
  4. ✓ Setup complete!
✓ Total setup time: 1-2 hours for complete design system + auto-generation
